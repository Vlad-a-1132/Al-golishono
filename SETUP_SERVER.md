# Инструкция по настройке сервера для работы форм

## Проблема
Контактные формы на сайте http://83.222.12.72/ не работают.

## Решение

Формы уже настроены и отправляют данные на API endpoint `/api/appointment`. Код работает корректно, но требуется настройка переменных окружения на сервере.

### Что нужно сделать на сервере:

#### 1. Создать файл `.env.local` в корне проекта

На сервере создайте файл `.env.local` со следующим содержимым:

```env
# SMTP настройки для отправки email
SMTP_HOST=smtp.mastermail.ru
SMTP_PORT=25
SMTP_USER=zakaz@altamed-c.ru
SMTP_PASSWORD=201Rect8*=
EMAIL_TO=zakaz@altamed-c.ru
```



#### 2. Создать папку для хранения заявок

```bash
mkdir -p data
chmod 755 data
```

Папка `data` будет использоваться для хранения файла `appointments.json` с заявками.

#### 3. Перезапустить приложение Next.js

После создания `.env.local` нужно перезапустить приложение:

```bash
# Если используется PM2
pm2 restart altamed-sait

# Или если используется systemd
systemctl restart altamed-sait

# Или просто перезапустите процесс Node.js
```

## Как работают формы

### 1. Форма записи на прием (`AppointmentForm`)
- Поля: Имя, Телефон
- Отправка: POST `/api/appointment`
- Данные сохраняются в `data/appointments.json`
- Email отправляется на адрес из `EMAIL_TO`

### 2. Форма обратного звонка (всплывающее окно)
- Поля: Имя, Телефон
- Отправка: POST `/api/appointment`
- Тип: "Обратный звонок"

### 3. Форма обратной связи (страница контактов)
- Поля: Имя, Телефон, Email, Сообщение
- Отправка: POST `/api/appointment`
- Тип: "Обратная связь (контакты)"

## Тестирование

После настройки проверьте работу форм:

1. Откройте http://83.222.12.72/
2. Нажмите "Записаться на прием"
3. Заполните форму и отправьте
4. Должно появиться сообщение: "Заявка успешно отправлена! Мы свяжемся с вами в ближайшее время."

## Просмотр заявок

Заявки сохраняются в файл `data/appointments.json` и доступны по API:

```bash
# Получить все заявки
curl http://83.222.12.72/api/appointment
```

## Альтернативное решение (если нет доступа к SMTP)

Если нет возможности настроить SMTP, можно использовать внешний сервис:

### Вариант 1: Telegram Bot API

1. Создайте Telegram бота через @BotFather
2. Получите токен бота
3. Добавьте в `.env.local`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_CHAT_ID=ваш_chat_id
```
4. Модифицируйте код для отправки в Telegram вместо email

### Вариант 2: Gmail SMTP

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=ваш_email@gmail.com
SMTP_PASSWORD=app_password
EMAIL_TO=zakaz@altamed-c.ru
```

**ВАЖНО:** Для Gmail нужно создать App Password в настройках безопасности Google аккаунта.

### Вариант 3: SendGrid / Mailgun

Использовать внешний сервис для отправки email:

```env
SENDGRID_API_KEY=ваш_api_ключ
EMAIL_TO=zakaz@altamed-c.ru
```

## Проверка логов

Проверьте логи приложения для диагностики проблем:

```bash
# Если используется PM2
pm2 logs altamed-sait

# Или смотрите логи Node.js процесса
```

В логах будут видны сообщения:
- `=== НОВАЯ ЗАЯВКА СОХРАНЕНА ===` - когда заявка успешно сохранена
- `Email отправлен:` - когда email успешно отправлен
- `Ошибка отправки email:` - если возникла ошибка с email (не критично, заявка всё равно сохраняется)

## Контакты для вопросов

Если возникнут проблемы при настройке, проверьте:
1. Файл `.env.local` создан и доступен для чтения
2. Пароль от SMTP указан правильно
3. Папка `data` существует и доступна для записи
4. Next.js приложение перезапущено после создания `.env.local`
