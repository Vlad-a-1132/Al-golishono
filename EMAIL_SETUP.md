# Инструкция по настройке отправки email через MasterMail

## Где взять SMTP настройки для MasterMail?

MasterMail использует стандартные SMTP настройки:

**Основные параметры:**
- SMTP сервер: `smtp.mastermail.ru` или `mail.mastermail.ru`
- Порт: `587` (TLS) - рекомендуется, или `465` (SSL)
- Безопасность: TLS для порта 587, SSL для порта 465

**Данные для входа:**
- Email: ваш полный email адрес (например: zakaz@altamed-c.ru)
- Пароль: ваш обычный пароль от почты MasterMail

## Как настроить:

1. Создайте файл `.env.local` в корне проекта (скопируйте из `env.example.txt`)

2. Заполните данные:
   ```
   SMTP_HOST=smtp.mastermail.ru
   SMTP_PORT=587
   SMTP_USER=zakaz@altamed-c.ru
   SMTP_PASSWORD=201Rect8*=
   EMAIL_TO=zakaz@altamed-c.ru
   ```

3. **ВАЖНО:** Перезапустите сервер разработки после создания/изменения .env.local:
   ```bash
   # Остановите сервер (Ctrl+C) и запустите снова:
   npm run dev
   ```

## Проверка работы:

1. Отправьте тестовую заявку через форму на сайте
2. Проверьте консоль сервера (терминал, где запущен `npm run dev`) - там должны быть логи:
   - `=== НОВАЯ ЗАЯВКА СОХРАНЕНА ===`
   - `Email отправлен: [messageId]` - если email отправился успешно
   - Или `Ошибка отправки email: [описание ошибки]` - если была ошибка

3. Проверьте почту на https://nm.mastermail.ru/owa/#path=/mail

## Возможные проблемы:

**Если email не отправляется:**

1. **Проверьте логи сервера** - там будет точная ошибка
2. **Проверьте настройки SMTP:**
   - Убедитесь, что пароль правильный
   - Попробуйте порт 465 вместо 587 (измените `SMTP_PORT=465` и `secure: true`)
   - Попробуйте `mail.mastermail.ru` вместо `smtp.mastermail.ru`

3. **Альтернативные настройки для MasterMail:**
   ```
   SMTP_HOST=mail.mastermail.ru
   SMTP_PORT=465
   # И в коде изменить secure: true
   ```

## Важно:

- Файл `.env.local` уже добавлен в `.gitignore` и не будет загружен в Git
- После изменения `.env.local` ОБЯЗАТЕЛЬНО перезапустите сервер
- Ошибки в консоли браузера от расширений Chrome не влияют на работу сайта
