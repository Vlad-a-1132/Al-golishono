# Финальная инструкция по настройке сервера

## Что нужно сделать на сервере http://83.222.12.72/

### Шаг 1: Создать файл `.env.local`

В корне проекта Next.js на сервере создайте файл `.env.local` с ТОЧНО таким содержимым:

```env
# SMTP настройки для отправки email
SMTP_HOST=smtp.mastermail.ru
SMTP_PORT=25
SMTP_USER=zakaz@altamed-c.ru
SMTP_PASSWORD=201Rect8*=
EMAIL_TO=zakaz@altamed-c.ru
```

### Шаг 2: Создать папку data

```bash
cd /path/to/your/nextjs/project
mkdir -p data
chmod 755 data
```

### Шаг 3: Перезапустить приложение

```bash
# Перезапустите ваш Next.js сервер
# Если используете PM2:
pm2 restart all

# Если используете другой процесс-менеджер, перезапустите его
```

### Шаг 4: Проверить работу

1. Откройте http://83.222.12.72/
2. Нажмите кнопку "Записаться на прием" внизу страницы
3. Заполните форму (введите имя и телефон)
4. Нажмите "Записаться онлайн"
5. Должно появиться зеленое сообщение: "Заявка успешно отправлена! Мы свяжемся с вами в ближайшее время."

### Шаг 5: Проверить почту

На zakaz@altamed-c.ru должно прийти письмо с темой:
- "Запись на прием - новая заявка с сайта"
- или "Обратный звонок - новая заявка с сайта"
- или "Обратная связь (контакты) - новая заявка с сайта"

В письме будут данные: имя, телефон, дата/время, ID заявки.

### Шаг 6: Просмотр всех заявок

Все заявки также сохраняются в файл и доступны по API:

```bash
curl http://83.222.12.72/api/appointment
```

Или откройте в браузере: http://83.222.12.72/api/appointment

## Возможные проблемы и решения:

### Проблема 1: "Ошибка при отправке формы"
**Решение:** Проверьте, что файл `.env.local` создан в правильной папке (корень проекта Next.js) и Next.js перезапущен.

### Проблема 2: Форма отправляется, но письма не приходят
**Решение:** 
1. Проверьте логи: `pm2 logs` (или другой способ просмотра логов)
2. Убедитесь, что пароль SMTP правильный: `201Rect8*=`
3. Проверьте, что порт 25 не заблокирован файрволом

### Проблема 3: Ошибка "Cannot POST /api/appointment"
**Решение:** Убедитесь, что сервер Next.js запущен в production режиме:
```bash
npm run build
npm start
```

## Техническая информация:

- **API Endpoint:** POST http://83.222.12.72/api/appointment
- **Формат данных:** JSON с полями: name, phone, message (опционально), email (опционально)
- **Ответ при успехе:** `{ "message": "Заявка сохранена", "id": "1234567890" }`
- **Ответ при ошибке:** `{ "error": "Описание ошибки" }`
- **Хранение данных:** `data/appointments.json` (создается автоматически)
- **SMTP:** smtp.mastermail.ru:25 (без SSL, с STARTTLS)
